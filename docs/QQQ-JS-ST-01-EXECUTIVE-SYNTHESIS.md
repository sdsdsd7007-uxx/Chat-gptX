## 1. Strategic premise
The official book description says the work aims to help readers see and understand reality, consider the future, and use planning tools appropriately. It expressly distinguishes strategic thinking (the mental method that shapes choices) from strategic planning (the tools used to structure projects and actions).

This implies a practical discipline: improve the framing and quality of thought before optimizing the plan template.

## 2. Three learning pillars

### A. Look beyond the immediate task
Start by seeing the whole situation: context, stakeholders, constraints, forces, changes and possible futures. Distinguish urgent symptoms from the underlying decision problem. Forecasts are hypotheses and should include uncertainty; this principle does not justify a guaranteed 72/120-hour disaster forecast.

### B. Test the mental model
A decision depends on the categories, assumptions and frame used to interpret reality. Write assumptions down, ask researchable questions, seek disconfirming evidence, and compare alternative explanations before committing. A confident narrative is not evidence that the framing is correct.

### C. Connect direction to means and execution
The book's published contents include internal and external analysis, resources/capabilities, vision, mission, values, objectives and policies. The QQQ application is to check that a desired outcome fits the selected approach and available resources. The “ends–ways–means” phrase is used here as an additional operational heuristic; it is not attributed as a direct quotation or named formula from the book without page-level evidence.

## 3. First practical tool: Strategic Framing Canvas

| Prompt | What to record | Quality check |
|---|---|---|
| Situation | What is happening, where and when? | Separate verified facts from assumptions |
| Core challenge | What decision/problem matters most? | Do not confuse symptom and cause |
| Purpose & values | Desired outcome and non-negotiable constraints | Name trade-offs explicitly |
| External context | Stakeholders, rules, technology, economy, trends | Include opportunities and threats |
| Internal capability | Skills, data, time, resources, authority | Identify missing capabilities |
| Choices | Plausible options, including “do nothing” | State what is deliberately excluded |
| Scenarios | Baseline, disruption, alternative future | State assumptions and uncertainty |
| Execution | Owner, next step, timing, dependencies | Bound scope and reversibility |
| Evidence | Measures that support or falsify the plan | Define source, baseline and window |
| Review | Date/trigger for adjustment | Record what would change the decision |

## 4. Applying the canvas to QQQ

**Decision question:** Should a proposed AI model or connector be allowed into production?

1. **Verified starting point:** QQQ architecture/validation documentation and a local dashboard prototype exist. That alone does not establish that the provider or connector is live.
2. **External factors:** feature fit, release changes, data-retention terms, availability, vendor dependence, price and regional restrictions.
3. **Internal capability:** approved credentials, adapter contract, test environment, data owner, security reviewer and rollback path.
4. **Choices:** (a) do not integrate yet, (b) evaluate offline using synthetic data, (c) run a read-only staging pilot, (d) request bounded production access only after acceptance.
5. **Recommended first step:** synthetic-data offline test followed by isolated read-only staging, if explicitly authorized.
6. **Evidence gate:** exact model/endpoint, repeatable task tests, source/citation checks, cost and latency measures, privacy/security review, negative tests and rollback.
7. **Stop condition:** missing approval, unclear data rights, sensitive data without approval, unbounded permissions, failed security tests or absent rollback.
8. **Review:** compare measured outcomes with a predeclared baseline; keep disagreements and failures in the report.

This is an original QQQ case exercise, not a case study quoted from the book.

## 5. Link to the published book structure

The official PDF's table of contents indicates three broad movements:
1. **Strategy foundations:** where strategy sits in organizational action; definitions and components; values, mission, vision, external environment, internal resources/capabilities and competitive advantage.
2. **Strategic thinking:** distinction from planning; perspective and paradigm change; cognitive obstacles; leader development; research questions and practices for handling response, leverage, change, maneuver and external pressure.
3. **Strategy formation:** external and internal analysis; theory of action; vision, mission, values, objectives and policies, followed by appendices on strategic schools and forms of strategy.

This is a concise guide to the published structure, not a replacement for the work. Detailed chapter notes should be written only after checking the exact edition and relevant page references.

## 7. Learning checks
1. Explain the difference between strategic thinking and strategic planning in your own words.
2. Identify one assumption behind a current project decision and name evidence that could disconfirm it.
3. List one external opportunity, one external risk, one internal capability and one capability gap.
4. Write two genuinely different options before choosing a plan.
5. Define one outcome measure and the source/time window needed to assess it.
6. State what new evidence would cause the decision to be revised.
