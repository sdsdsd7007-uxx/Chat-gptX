# UVSGM — Universal Value & Sustainable Governance Matrix
**Status:** Proposed value-to-control map; not activated.

## Purpose
Translate a human-approved values charter into observable operating rules and testable controls. Broad values do not replace applicable law, permission, privacy, safety, due process or accountable human decision-making.

| Value | Operational rule | Control/evidence |
|---|---|---|
| Itqan — quality | Validate claims, context and limitations | A missing denominator or failed critical check prevents VERIFIED status |
| Amanah — trust | Preserve provenance, confidentiality, permission and integrity | Source references, least privilege, redaction and audit review |
| Shura — consultation | Gather relevant perspectives and preserve disagreement | Independent domain review; no self-approval by the proposer |
| Adl — justice | Use comparable evidence, review affected groups and enable appeal | Incomparable cohorts blocked; correction route documented |
| Ihsan — care/excellence | Support accessibility, clarity and user usefulness | Critical accessibility or task failures block acceptance |
| Sustainability | Measure recurring cost, maintenance and long-term impact | Benefits require baseline and observed outcomes |
| Rahmah / harm minimization | Reduce avoidable harm and escalate sensitive cases | Human review, safe stop, appeal and remedy path |

## Governance order
1. Applicable law, permissions, privacy and safety.
2. Explicit scope, identity, deterministic policy and accountable owner decisions.
3. Human-approved values charter and domain-specific guidance.
4. Analysis and model-generated content.
5. Monitoring, independent evidence, correction and lessons learned.

A lower layer cannot override a higher layer. A generated explanation or claim of values alignment is not authorization evidence.

## Source and cultural integrity
The “Rahmah lil-'Alamin” library and religious/cultural references need a source register, edition/translation, context, intended audience, permitted use, qualified reviewer and correction pathway. Preserve source fidelity; do not present a generated paraphrase as universal consensus. AMAOG and SIONS remain non-canonical until an accountable owner confirms their definitions, interfaces and decision rights.

## Proposed tests — NOT RUN
- Missing provenance prevents VERIFIED status.
- Missing permission blocks data use.
- Reviewer disagreement is preserved and escalated.
- High-impact action without authenticated approval is blocked.
- Incomparable units/cohorts cannot be ranked silently.
- Critical accessibility issues block acceptance.
- A source lacking edition/context is held for qualified review.
- A changed approved action requires reauthorization.
- Retention expiry follows the approved retention policy.
- A faster result with quality/safety below the predeclared floor is rejected.
- Appeals/corrections produce a traceable review event.
- Ambiguous value conflicts escalate to an accountable human rather than a hidden score.

## Reporting
Track separately: rules proposed, rules reviewed, tests executed, passed, failed, waived and outcomes sampled. Coverage counts alone do not prove ethical effectiveness. Avoid an aggregate “100% ethics” KPI.
