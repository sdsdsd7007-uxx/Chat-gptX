## Prioritization

1. **P0 — Close the Project Q review gap:** independent security review, resolve findings, keep PR draft until then.
2. **P1 — Improve Project Z evidence quality:** build representative, licensed, independently judged test data; repeatable benchmark protocol.
3. **P2 — Create domain charters:** ZX3:1–5, EDU, Forum, Market X, GSSE and FOOD.
4. **P3 — Resolve higher-risk or undefined scopes:** PHARMA, DENTAL, ERP, LIVE, XSDONE and Yup require explicit boundaries before implementation.

## Portfolio completion rule

A register entry is not a delivered project. Mark a workstream verified only when its scoped artifact exists, tests and acceptance criteria pass, dependencies and risks are reviewed, ownership is recorded, and the result is independently checked. Production remains a separate approval gate.
